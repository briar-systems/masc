# what each riscv-opcodes argument is as an operand, and where it stands
#
#   group <args> | use=<use> position=|layout=|choice=<field>   the arguments that form one operand
#   rank <arg> | <rank>                                        where the argument's operand stands
#   rank immediate | <rank>, rank choice | <rank>              the rank of an immediate's and a modifier's operand
#   override <mnemonic> <args> | layout=|choice=<field>        a field a row takes for a group in place of its own
#   align <mnemonic> <arg> | position=<field> width=<state>    an aligned register group a row's argument names
#
# a use is register, immediate, choice, csr (the csr layout as an id of the
# csr space), adjust (zcmp's stack adjustment, which the stack kind encodes
# whole) or sreg (a zcmp s register, which the sregs kind encodes whole), and
# a field is one the fields topic states. the groups of several arguments come
# first so they are taken whole. ranks are lowest first, and in the order
# written among equals: destinations lead, then the vector source vs2 and a
# csr, the first, second and third sources, a register list, the immediates
# and last the modifiers. a mnemonic is matched with one `*` matching any run
# of characters, and the last override or align that matches is taken.
# riscv-opcodes names arguments and their bits, never the operand they form,
# so no line overrides it
