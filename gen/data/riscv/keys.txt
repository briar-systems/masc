# the riscv decode dispatch keys, in the order the dispatch prefers them: the
# length class, then the major opcode and the function fields of each length
#
#   key <name> | lo=<bit> len=<bits>     bits lo to lo + len - 1 of an instruction
#
# a key is a field of the instruction formats, read without consuming it, and
# its name is the field's. which keys the dispatch reads, and in what order, is
# masc's own choice, so no line overrides riscv-opcodes, which states the bits
# each record fixes and no key

key length | lo=0 len=2 | the length encoding of the manual's introduction, an instruction of 32 bits has its low two bits set | -

key opcode | lo=2 len=5 | riscv-opcodes 6..2; src/unpriv/rv32.adoc, the base instruction formats | -
