# the register class each riscv-opcodes register argument names
#
#   file <file> | float              its register arguments are f registers, but for the integers below
#   file <file> | compressed float   its data arguments are f registers and its address an x register
#   arg <arg> | compressed float     a data argument of a compressed floating-point load or store
#   file <file> | vector             its vd, vs1, vs2 and vs3 are v registers, its rd, rs1 and rs2 x registers
#   integer <mnemonic> | <args>      a float file's rows whose arguments name x registers, none for no argument
#   scalar <mnemonic> | float        a vector file's rows whose scalar rd and rs1 are f registers
#   scalar <mnemonic> | integer      a row a float scalar matches whose scalars are x registers all the same
#
# every other register argument names an x register, and a float file's loads
# and stores address through an x register by their major opcode. a mnemonic
# is matched with one `*` matching any run of characters, and the first
# integer that matches is taken. riscv-opcodes states no register class, so no
# line overrides it
