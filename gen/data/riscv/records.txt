# the records riscv-opcodes states otherwise than the manual, and those it
# does not state
#
#   rename <file>::<name> <major> | <name>   a record named wrongly, by its file, name and major opcode, overriding its name
#   extra <file> <name> | <fields>           a record of its own, in riscv-opcodes' syntax, overriding pseudo where
#                                            riscv-opcodes states it as a pseudo op
#   zeroed <file>::<name> | <args>           arguments its instruction holds at zero, overriding them as arguments
#   arg <name> | hi=<bit> lo=<bit>           an argument the extra records name that arg_lut.csv does not
#
# a zeroed argument is a fixed bit of the row, so masc writes zero and reads no
# instruction of the record from encodings that set it: the manual reserves its
# other values, which standard software zeroes, or gives them to another row

rename rv32_zilsd::ld 0x23 | sd | the manual's Zilsd chapter, the store pair whose major opcode is STORE is sd | ld
extra rv_zcmt cm.jt | "c_index_jt 1..0=2 15..13=5 12..10=0 9..7=0" | src/unpriv/zcmt.adoc, an index below 32 is cm.jt, a jump through the table rather than a call | -
extra rv_i fence.tso | "31..28=8 27..24=3 23..20=3 19..15=0 14..12=0 11..7=0 6..2=0x03 1..0=3" | src/unpriv/rv32.adoc "fence.tso", fence with fm 1000 and its sets rw | pseudo
extra rv_c c.nop.hint | "c_nzimm6hi c_nzimm6lo 1..0=1 15..13=0 11..7=0" | src/unpriv/zca.adoc "Zca HINT instructions", c.nop's nonzero immediates are hints, keyed apart from c.nop | -
zeroed rv_i::fence | "fm rd rs1" | src/unpriv/rv32.adoc, "The unused fields in the FENCE instructions, rs1 and rd, are reserved ... standard software shall zero these fields", and fm's one other value standard software uses is fence.tso's | arguments
zeroed rv_zifencei::fence.i | "imm12 rs1 rd" | src/unpriv/zifencei.adoc, "standard software shall zero these fields" | arguments
zeroed rv_c::c.nop | "c_nzimm6hi c_nzimm6lo" | src/unpriv/zca.adoc, the nonzero immediates of c.nop are hints, the extra record c.nop.hint | arguments
arg c_index_jt | hi=6 lo=2 | src/unpriv/zcmt.adoc, cm.jt's index, bits 6 to 2, which arg_lut.csv does not name | -
