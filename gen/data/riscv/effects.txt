# the effects of the riscv rows, which riscv-opcodes does not state
#
#   role <arg> | <role>                              the role of the operand an argument names, every other read
#   recast <mnemonic> <arg> | <role>                 a row's role for an argument in place of its default
#   undisturbed <mnemonic> <arg> | <role>            the role every other vector row's destination has
#   implicit <mnemonic> | at=<n> role=<role>         the stack pointer a row holds in its fixed bits, an operand at n,
#                                                    or `last` for after every other
#   stack pointer | <register>                       the register an implicit operand is fixed to
#   uses <mnemonic> | read=<registers> written=<registers>
#                                                    registers a row reads and writes that no operand names
#   saved <value> | <registers>                      the registers a list operand's value names
#   listed <mnemonic> <arg> | <role>                 a row whose list argument reads or writes the registers it names
#   config <mnemonic> | read=<state> written=<state> the vector configuration a row reads and writes
#   float <mnemonic> | read=<state> written=<state>  the floating-point state, `arg=<arg>` for a row that has it
#   fixed <mnemonic> | read=<state> written=<state>  the vector fixed-point state
#   register <mnemonic> | when=<term> read=<registers> written=<registers>
#                                                    registers a row adds while an argument meets the term
#   memory <mnemonic> | role=<role> element=<element> a scalar memory access and how its width is stated
#   control <mnemonic> | transfer=<transfer> target=<target>
#                                                    a control transfer, `conditional=yes` for one that may fall
#                                                    through and `arg=<arg>` for the argument holding its target
#   rule <mnemonic> | transfer=<transfer> target=<target> first=<term>
#                                                    the transfer a row has instead while its registers meet the
#                                                    term, and `second=<term>` too
#   adjust <mnemonic> | <arg>                        a change to the stack pointer by an argument's operand
#   latency <mnemonic> | <latency>                   a latency class
#   mark <mnemonic> | specifier=<key> fixup=<fixup> arg=<arg> register=<register>
#                                                    a marked copy of the row, a marker operand after its own
#   fixup <mnemonic> | <fixup>                       the fixup kind a symbol takes by default in a row's operand
#   split <mnemonic> | negative=<yes|no>             a row whose encoding differs by width, a row at each, and
#                                                    whether its stack adjustment is written negative
#   relax <mnemonic> | to=<row>                      the longer form of a row whose target is out of range, its
#                                                    first step `to`, `inverted=yes` for the inverted branch past
#                                                    a jump, and `link=<register>` for the register a form of one
#                                                    step takes in place of the one the row holds implicitly
#   far | row=<row> link=<register>                  the jump of an inverted branch's form and its link
#   fill | <rows>                                    the no-ops the code fill writes, longest first
#
# a mnemonic is matched with one `*` matching any run of characters, and the
# first line of a kind that matches is taken, but for the state kinds, each a
# domain of state whose first line that matches and has its argument is taken,
# so a line for an exception comes before the line for the rule it excepts,
# and the register lines, of which at most one may match a row. state that
# accrues (fflags, vxsat) is both read and written, since an instruction adds
# to what is there and a write that left it undefined would let a pass drop
# the sets before it. a role is read, write or read-write, a transfer jump,
# call, return, trap or none, a target direct, indirect or untargeted, and a
# latency one, few, many or serial. an element is `fixed bits=<n>`, `suffix`,
# the width the mnemonic's last part names (b 8, h 16, w 32, d 64, q 128),
# `xlen`, one register of the integer file, as zcmp saves, or `block`, a cache
# block whose size the platform states. a term is `<arg> in <registers>`, its
# register one of these, `<arg> = <n>`, its enumerant n, or `<arg> is <value>`,
# its enumerant the value the fields topic names so. a fixup is masc's riscv
# fixup named so, and a register the register file's name. a memory access's
# address is the row's address register, offset by its immediate when it has
# one, and for zcmp the stack pointer. facts are the riscv-isa-manual's at
# 36fdac54a526 and the riscv psabi's at 48969b7, which riscv-opcodes does not
# state, so no line overrides it
