# the register constraints and element widths of the vector rows, which
# riscv-opcodes does not state
#
#   keep <mnemonic> <arg> | against=<args>          the argument's groups kept from those of the arguments
#   keep <mnemonic> <arg> | register=<register>     the argument kept from the register, `masked=yes` while
#                                                   the row's mask argument is v0.t
#   element <mnemonic> <arg> | eew=<width> span=<span>
#                                                   the argument's element width and how its groups cover registers
#   masking | arg=<arg> register=<register>         the mask argument and the mask register it names
#   mask-reader <mnemonic> | <register>             a row that reads the mask register as a mask whatever its encoding
#   encoding <field> | lo=<bit>                     a field of the vector loads' and stores' encoding, by its low bit
#   segment <mnemonic> | <arg>                      a segment load's or store's data argument, one group per field
#
# a mnemonic is matched with one `*` matching any run of characters. at most
# one element line matches an argument of a row, and every keep line that
# matches is taken, each a reserved encoding when broken that keeps its
# argument apart whole. a width is a number of bits, or `sew`, `sew*2` or
# `sew/n` for a power of two n, the element width the vector state scales.
# a span is `scaled`, EMUL = (EEW/SEW)*LMUL ("Vector Operands", eew_emul),
# `packed`, a mask of one bit per element in one register ("Mask Register
# Layout"), `scalar elements=<n>`, a group of n elements from element 0
# whatever LMUL, as a reduction's scalar or a .vs crypto round's element group
# of four, covering ceil(n*EEW/VLEN) registers at the least VLEN the selection
# admits, or `whole registers=<n>`, n registers whatever the state, as
# vmv<nr>r.v's. every other vector argument is at SEW and LMUL.
#
# "Vector Operands" (vreg_overlap_legal, vreg_source_eew_rsv) is derived from
# the element widths: a destination keeps from each source of another width,
# and two sources of different widths keep apart. a source is a vector argument
# the row reads as an operand, the destination where the effects topic recasts
# it read, never for the undisturbed policies' read. a pair a keep line keeps
# apart whole states no rule of its widths, and a reduction's destination keeps
# from nothing. "Vector Masking" (vreg_vmask_rsv): a masked instruction's
# destination cannot overlap the mask register unless it is written with a mask
# value or a reduction's scalar, and each source of another width than a mask's
# keeps from it while the mask argument is v0.t, and always in a mask reader.
# nf's place is riscv-opcodes' own argument. facts are the riscv-isa-manual's
# at 36fdac54a526, which riscv-opcodes does not state, so no line overrides it
