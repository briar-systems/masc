# how the vendor tools spell the riscv rows, which riscv-opcodes does not state
#
#   respell <name> | args=<args> order=<order>      a respelling: the arguments its record leaves free, in the
#                                                   record's order with a binding such as `rs2=rs1` as written,
#                                                   and the free arguments in written order. `zero=<args>` names
#                                                   free arguments the written form fixes to zero, `print=no` one
#                                                   the printer does not prefer to the base's own spelling,
#                                                   `text=<template>` its template when it is not the operands in
#                                                   order, and `skip=<why>` one that makes no alias
#   default <choice> | <value>                      a value of an enumerant left unwritten, which every row whose
#                                                   operand takes the choice has a preferred alias without
#   exclude <name> <arg> | <value>                  a value a respelling never takes though its operand admits it
#   format <arg> | <format>                         an operand written with a format the syntax's immediate hook reads
#   template <mnemonic> | <text>                    a row whose spelling is not its operands in rank order
#   order <mnemonic> | reversed                     a row that writes its multiplicand before its multiplier
#   carry <mnemonic> | v0                           a row that reads the mask register as an operand of its own,
#                                                   written `v0` after the others
#
# riscv-opcodes states encodings, and nothing of how an assembler spells them:
# which operand comes first, which are glued to the mnemonic, and which
# alternative spellings the vendor tools read and print. a respelling is the
# same instruction under another mnemonic, and riscv-opcodes lists its
# arguments in bit order, so each states its written order here, from the
# riscv-asm-manual for the base set and from llvm's InstAliases for the
# extensions. the generator refuses a respelling no line states, or whose
# arguments differ from the record's, and an exclusion of a value its base
# operand admits that no respelling takes, so a new extension file is reviewed
# here before it is spelled. no respelling's manual section reserves a value
# its base admits, so no exclusion is stated. a name ending in `*` matches any
# run, argument names are riscv-opcodes' own, a name in an order standing for
# the operand whose bits it covers, and a template writes `$` for its mnemonic
# and `<argument>` for an operand. a choice and its values are the fields
# topic's. riscv-opcodes states none of this, so no line overrides it
