# the riscv operand fields: the layouts of immediates, the enumerant choices,
# the register positions, the values they exclude, and the field kinds' indices
#
#   integers <name> | <numbers>          values an immediate never admits
#   numbers <name> | <numbers>           register numbers a position never admits
#   value <name> | <number>              an enumerant value the set's modules name
#   member <set> | "<name>" <value>      the next member of an enumerant set, its value a number or a value
#   layout <name> | <words>              unit, pieces lo:len@at, bits, sign, scale, bias, excluded, relative
#   immediate <name> | <words>           an immediate a field kind encodes whole
#   choice <name> | <words>              unit, pieces and members
#   position <name> | <words>            unit, at, len, first, count, excluded and group
#   kind <name> | <number>               a field kind's index in masc's riscv field table
#
# riscv-opcodes names each argument and its bits, never how the bits form one
# number, what values it admits, or how its enumerants are spelled, so no line
# overrides it. the arguments a layout or position covers are named in its
# cites as riscv-opcodes spells them. not covered: the rv128 shamtq, the quad
# compressed c_uimm9, c_uimm10 and their stack forms, and the unratified p
# extension and zvt arguments. imm2, imm3, imm4 and rc are no argument of a
# ratified file, and no row takes them
