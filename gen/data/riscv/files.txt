# the extensions each riscv-opcodes file's instructions require, in the
# catalog's spelling
#
#   file <file> | requires=<requirement>        every instruction of the file requires it
#   file <file> | skip=<reason>                 a file read for no rows, and why
#   member <file> <mnemonic> | requires=<req>   the instructions of a file that holds several extensions
#
# a requirement is alternatives split by `|`, the atoms of one alternative by
# spaces, an extension or a state value as `xlen=32`, and empty for none. a
# member's mnemonic ending in `*` matches any mnemonic with that prefix, and
# the first member that matches is taken. riscv-opcodes names a file by its
# extension and states no requirement, so no line overrides it
#
# the files that hold more than one extension, from the manual: rv_a and
# rv64_a hold zalrsc and zaamo, rv_m and rv64_m the multiplies of zmmul,
# rv_zicbo zicbom, zicboz and zicbop's prefetches, rv_zvbb zvkb, the proper
# subset of zvbb that zvbb, zvkn and zvks all imply, and rv_v's floating point
# instructions need zve32f, vfirst.m being a mask instruction, and its accesses
# of 64-bit elements or indices zve64x. some zcb instructions need another
# extension too, rv_i's pause is zihintpause's, and some rows of a file of
# every width exist only at rv64
