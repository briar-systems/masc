# the compressions of the vendor tools, each written against the instruction
# it shortens
#
#   compress <base> <packed> | from=<operands> when=<conditions>   the base row's compressed form
#
# riscv-opcodes states the compressed encodings and not what they stand for.
# each line is read from the expansion column of the manual's RVC instruction
# listings, the zcb chapter, and zicfiss's c.sspush and c.sspopchk, or, for a
# form the listings do not expand to, as addiw with rs1 zero to c.li or an
# operand pair commuted, from the patterns llvm compresses by (its RVC and Zc
# instruction definitions, checked against llvm-mc 23.1.1). a base's lines are
# tried in the order given, the order the vendor tools prefer, and each is
# written for every row of both mnemonics but a marked one, so a compressed
# form with an rv32 and an rv64 row is a compression of each. whether a value
# fits is the shorter row's own check.
#
# `from` is, for each operand of the shorter row in order, the argument of the
# base row it takes its value from, `a|b` for whichever of the two the base
# row has, `a:s20` for that operand's number sign extended from twenty bits,
# and `=x2` for a fixed register. `when` is the conditions on the base row's
# values: `a=b` for two arguments holding one value, `a=x0` for an argument
# holding a register, and `a=#255` for a number. riscv-opcodes states none of
# this, so no line overrides it
