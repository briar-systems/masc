# the mnemonic a row is also read under
#
#   respell <mnemonic> | <mnemonic>
#
# a load or store of a base and an offset has a scaled unsigned form and an unscaled signed one, and an offset only the
# unscaled form holds, as a negative or unaligned one, has one encoding of the access, so the scaled form's mnemonic
# reads as the unscaled row where the scaled rows refuse the offset. the rows print under their own mnemonic. the
# model states no respelling, so no line overrides it
