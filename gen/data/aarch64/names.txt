# the names a consumer spells an extension by that llvm 23.1.1 gives none, each an alias of the rows it states
#
#   name <name> | <FEAT_*>...
#
# llvm folds FEAT_PMULL into its aes (AArch64Features.td, FeatureAES "FEAT_AES, FEAT_PMULL"), but a processor may
# implement FEAT_AES without it (DDI 0487, ID_AA64ISAR0_EL1.AES 0b0001 against 0b0010, which adds PMULL), and Linux
# reports the two apart (HWCAP_AES and HWCAP_PMULL, /proc/cpuinfo's aes and pmull), as mach-std's cpu features read
# them. a line restates nothing llvm states, so llvm coming to give a name refuses its line

name pmull | FEAT_PMULL | DDI 0487 ID_AA64ISAR0_EL1.AES 0b0010 "FEAT_PMULL implemented", Linux arch/arm64/kernel/cpuinfo.c hwcap_str "pmull", mach-std src/system/cpu/features.mach pmull | -
