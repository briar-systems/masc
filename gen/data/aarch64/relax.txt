# the far branch a branch out of range relaxes past, and the code fill
#
#   far | row=<row>
#   fill | row=<row>
#
# a branch past its range becomes its inverse, as the inverses topic states it, past the far branch to the target:
# cb<cc>'s nine bits reach 1KB, tbz's fourteen 32KB and cbz's and b.cond's nineteen 1MB, b's twenty-six 128MB. a branch
# with no inverse, as b.cond on al or nv, has no longer form. llvm-mc 23.1.1 and GNU as relax no aarch64 branch and
# refuse one out of range, so these are masc's own. the model states no relaxation, so no line overrides it

far | row=B_only_branch_imm | A64 ISA XML b_uncond.xml, "B": a branch to a label within 128MB | -
fill | row=NOP_HI_hints | A64 ISA XML nop.xml, "NOP"; llvm 23.1.1 AArch64AsmBackend::writeNopData writes 0xd503201f | -
