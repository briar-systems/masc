# the inverse of each conditional branch, the branch that jumps where it does not
#
#   invert <row> | to=<row> [flip=<mask> fixed=<member>,...] [args=<arg>,...]
#
# cb<cc> has no inverse of each condition in its own encoding, so its inverse is another condition over swapped
# registers, as cbgt x0, x1's is cbge x1, x0, or over the immediate one more or one less, as cbgt x0, #1's is
# cblt x0, #2 (A64 ISA XML cbcc_regs.xml and cbcc_imm.xml, and the aliases cble_regs.xml and cble_imm.xml), and an
# immediate past imm6's 0 to 63 leaves the branch no inverse. a condition inverts by its low bit, but al and nv both
# mean always (DDI 0487 Table C1-1, "Standard condition codes"), so a branch on either has no inverse. the model states
# no inverse, so no line overrides it
