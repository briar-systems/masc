# what each operand rule of Arm's instruction model is as an operand, and where it stands
#
#   register <rule> | class=<classes> role=<role> [first=<n>]
#     a register its fields' bits number, of the first class, or of the last where the text is the choice of that
#     class's one name and the numbered text, as `(XZR|X{UInteger})`. `first` is the number the encoded zero names
#   immediate <rule> | <unsigned|signed> [scale=<n>] [bias=<n>]
#     a number held by its fields' bits the row leaves free, `scale` low zero bits no field holds, `bias` added
#   choice <rule> | <rows|enumerant> <member>=<bits> ...
#     each member by the text it spells and the bits of the choice's fields it encodes from the high bit, `x` for a
#     bit another operand holds, `:` between fields. `rows` makes a row of each member, as an element size that fixes
#     other operands' widths, and `enumerant` is one operand of the members' values
#   element <specifier> | bits=<n> [lanes=<n>]
#     the width of each element of a register written `.<specifier>`, and how many it holds
#
# a role is read, write, read-write or none. the instruction model (AARCHMRS) states each rule's text and the fields
# it is encoded in and redacts what the text means, so every fact here is read from the instruction's page of the
# Arm Architecture Reference Manual (DDI 0487) as the A64 ISA XML 2026-06 states it, cited by its file and symbol,
# and no line overrides the model
