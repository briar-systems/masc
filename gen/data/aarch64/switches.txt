# how code switches a state value itself: the rows that save the state into a register, set it to the value, and set it
# back from that register
#
#   switch <axis>=<value> | saved=<class> mask=<bits> held=<bits> [scratch=<class>,...]
#   read <axis>=<value> | row=<row> args=<source>,...
#   set <axis>=<value> | row=<row> args=<source>,...
#   restore <axis>=<value> | row=<row> args=<source>,...
#
# `saved` is the class of the register the read saves the state into, `mask` the bits of it that hold the state and
# `held` those bits while the state is at the value, and `scratch` the class of each scratch register by its index. rows
# are named by key, and a sequence of more than one instruction is its lines in file order. each source of `args` is,
# for each operand of the row in order, `saved`, the saved register, `scratch:<n>`, the scratch register of index n,
# `register:<name>`, a register of the file by name, `immediate:<n>`, or `enumerant:<name>`, the member of an enumerant
# operand by name. PSTATE.DIT is read into bit 24 of a general register and written back from it with mrs and msr of the
# system register dit, and set with msr of the pstate field, each at el0, so a constant-time function switches it
# around its own code. the set is followed by dsb nsh and isb sy, as std.system.dit.enable does, so no instruction
# after it runs speculatively under the timing before it. the restore leaves the mode, and the code after it needs no
# guarantee. the model states no switch, so no line overrides it

switch dit=on | saved=x mask=0x1000000 held=0x1000000 | DDI 0487 "DIT, Data Independent Timing": DIT is bit 24, accessible at EL0 with FEAT_DIT | -
read dit=on | row=MRS_RS_systemmove args=saved,register:dit | A64 ISA XML mrs.xml, "MRS"; DDI 0487 "DIT, Data Independent Timing": "MRS <Xt>, DIT" | -
set dit=on | row=MSR_SI_pstate.dit args=immediate:1 | A64 ISA XML msr_imm.xml, "MSR (immediate)": DIT is set to CRm<0>; DDI 0487 "DIT, Data Independent Timing": "MSR DIT, #<imm>" | -
set dit=on | row=DSB_BO_barriers args=enumerant:nsh | A64 ISA XML dsb.xml, "DSB": option nsh; Apple, "Writing ARM64 code for Apple platforms", enabling DIT: a speculation barrier follows the write | -
set dit=on | row=ISB_BI_barriers args=enumerant:sy | A64 ISA XML isb.xml, "ISB": option sy | -
restore dit=on | row=MSR_SR_systemmove args=register:dit,saved | A64 ISA XML msr_reg.xml, "MSR (register)"; DDI 0487 "DIT, Data Independent Timing": "MSR DIT, <Xt>" writes DIT from bit 24 | -
