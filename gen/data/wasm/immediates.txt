# the immediates of the wasm instructions, which opcode.def does not state
#
#   imm <Name> | <immediate>... [order=<i>,<j>...] [paired=yes]
#
# Name is opcode.def's identifier of the instruction. the immediates follow the instruction's opcode in binary order,
# each an operand of the row. a memory instruction, one opcode.def states a memory access size for (its `m` column),
# takes its memarg first by the source alone, so a line here states only what follows it, as a lane. `order` gives
# the operands in the order the text spells them, where it differs from binary order, and `paired` makes its two
# optional indices one pair the text gives both of or neither. an immediate is one of:
#
#   blocktype   the block type, a group of an optional value type and an optional type index, exactly one present,
#               which the text may leave out for the empty block type
#   catches     a try_table's catch clauses, each a group of its kind, its tag index where the kind names one, and
#               its label
#   labelidx    a label, by its depth
#   labels      br_table's labels and its default after them, one list
#   typeidx     a type index
#   typeuse     a type index the text spells as a type use, `(type x)` and its params and results
#   funcidx, tableidx, memidx, globalidx, localidx, tagidx, dataidx, elemidx
#               an index into that space. a trailing `?` makes it one the text may leave out, which then reads as 0
#   valtypes    select's value types
#   heaptype    a heap type, an abstract one or a type index
#   i32, i64    an integer, its signed LEB128
#   f32, f64    a float, its bytes little-endian
#   v128        a 128-bit constant, its 16 bytes
#   lane        a lane index, one byte
#   lanes       i8x16.shuffle's 16 lane indices, a byte each
#   zero        a reserved byte, 0, which is no operand
#
# every cite is to the WebAssembly Specification release 3.0, tag wg-3.0, specification/wasm-3.0: 5.3 is
# 5.3-binary.instructions.spectec and 6.3 is 6.3-text.instructions.spectec. the threads proposal's instructions cite
# its proposals/threads/Overview.md at cc535ada1aa21cfaa3cabf3ac73b89acef78a0a0
