# the instructions of opcode.def and of the specification's index that are not rows
#
#   omit <Name> | <why>                    an instruction of opcode.def that is no row
#   unrowed <opcode> | <why>               an instruction the index names that no row is
#   unindexed <prefix> | <why>             a prefix whose rows the index does not name
#
# an opcode is `0x..` for a one-byte opcode, or the prefix and its index, as `0xfb 0x00-0x1e` for a
# range. a row the index does not name, or an index entry no row is, is refused unless a line here
# names it
#
# every line cites the WebAssembly Specification release 3.0, tag wg-3.0, its index of instructions
# (document/core/appendix/index-instructions.py), as `index`, or wabt 1.0.42's opcode.def
