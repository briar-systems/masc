# the feature each instruction requires, which opcode.def does not state
#
#   feature <opcode> | <feature>
#
# an opcode is `0x..` for a one-byte opcode, or the prefix and its index, as `0xfc 0x00-0x07` for a
# range, and the feature a row of the catalog (features/extensions.txt). an instruction no line
# names is of wasm 1.0 and requires nothing, and a line naming several features requires every one. a
# feature its immediates require for some values only,
# as multimemory for a memory index other than 0 and multivalue for a block type by type index, is the
# kinds' to admit, so no line names it
#
# every line cites the WebAssembly Specification release 3.0, tag wg-3.0, its appendix's change
# history (document/core/appendix/changes.rst), which names the instructions each proposal adds, as
# `changes`, or the threads proposal (proposals/threads/Overview.md, cc535ada1aa21cfaa3cabf3ac73b89acef78a0a0)
