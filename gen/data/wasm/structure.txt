# the structured instructions, which opcode.def does not state
#
#   structure <Name> | else|close|loop|catch
#
# block, loop, if and try_table open a block, which the stream's label stack holds until its end
# closes it, and the generator reads an opening from the block type the instruction takes
# (immediates.txt) so no line restates it. a block's label is its end, but loop's is its start, and
# try_table's catches take control to labels from any throw in its body, which `loop` and `catch` state
# of an opening. else ends an if's first arm and starts its second within the same block, and end
# closes the innermost block, or a function's body at its outermost
#
# every line cites the WebAssembly Specification release 3.0, tag wg-3.0, 2.4.8 control instructions
# (specification/wasm-3.0/1.3-syntax.instructions.spectec), as `syntax`, or 4.4.8 control instructions
# (specification/wasm-3.0/4.3-execution.instructions.spectec), as `exec`

structure Else | else | syntax, if bt instr1* else instr2* end | -
structure End | close | syntax, every structured instruction ends with end | -
structure Loop | loop | exec, the label of loop is its start, so br to it runs the loop again | -
structure TryTable | catch | exec, try_table bt catch* instr* end, a throw in instr* takes control to the label of the catch that matches | -
