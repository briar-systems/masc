# the handle kind of each image-family id operand, read off the name the grammar gives it, which the grammar does not
# state, since it names every id an IdRef
#
#   name "<name>" | image|sampler|sampled|image-pointer|none
#   operand <opname> <operand> | <kind>
#   result <opname> | <kind>
#
# a name line gives every id operand of that name its kind: an OpTypeImage (`image`), an OpTypeSampler (`sampler`), an
# OpTypeSampledImage (`sampled`), a pointer whose pointee is an OpTypeImage (`image-pointer`), or none for an id that
# names no handle, as a type or a value. an operand line gives the operand of that number another kind than its
# name's, and a result line gives an instruction's result a kind. every IdRef operand whose name holds image, sampler
# or texture, in any case, has a name or operand line. an image a storage read or write takes is `image` too, since its
# type's Sampled operand, not its name, tells a storage image
#
# every line cites the SPIR-V 1.6 rev 7 specification
