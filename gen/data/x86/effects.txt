# the values rows write as functions of the values they read, which XED does not state
#
#   <ICLASS> [op=<opcode>] [byte=0x<hex>] [size=o16|o32|o64] [width=16|32|64] [prefix=p66|pf3|pf2] [w=0|1] [nf=0|1]
#   [nd=0|1] [form=reg|mem|ptr] | offset <relation> | <cites> | -
#   <ICLASS> [...] | trap returns=<yes|no> [conditional=yes] | <cites> | -
#
# a line names rows as the mnemonics topic's do and states the relation of each (gen.relation), its operands by their
# numbers in XED's order: the register written, the register read and the immediate added, or for lea the memory
# operand whose base it reads and whose displacement it adds. a relation holds in the low bits of the narrower register
# it names, so a 32-bit add's states nothing of the bits its write zeroes above them. an apx nd row writes its new data
# destination, operand 0, from operand 1. a line naming no row, or an operand a row lacks, is refused
#
# a trap line states the trap a row takes, which XED's category names without its kind: `returns=yes` for one whose
# handler resumes at the next instruction, `returns=no` for one nothing falls through after (gen.control), and
# `conditional=yes` for one some values skip. what it writes by the architecture XED states, as syscall's rcx and r11.
# every row of XED's SYSCALL and INTERRUPT categories has a line, and hlt has none: it waits at the privilege it
# requires and resumes at the next instruction, as risc-v wfi does, and its #GP below that privilege is any
# privileged instruction's
