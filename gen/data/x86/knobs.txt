# the value masc's decoder reads each of XED's decoder knobs at
#
#   <XED field> | <value> | <cites> | -
#
# XED's patterns test fields no prefix or byte gives, which a user of XED's decoder sets to choose how bytes one
# processor and another read differently are decoded: a feature that turns a nop or an ignored prefix into an
# instruction, and a reading older processors alone have. masc reads the bytes as a processor with every feature does,
# as llvm-objdump 23.1.1 decodes them, so a feature's instruction is a row that requires the feature, and the reading
# a knob's other value gives is none of masc's rows. XED states the fields and no value of them, so no line overrides
# it
