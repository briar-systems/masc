# the atom of the x86 catalog each cpuid name of XED stands for, where it is not the name of a row
#
#   <cpuid name> | <atom> | <cites> | -
#
# a cpuid name that is a row's own name stands for that row, which is what XED states, so a line
# for it would restate it. the rest are spellings of XED's own: the manifest spelling the catalog
# gives the row (sse4 is sse41, pclmulqdq pclmul), an enable bit that is part of its feature's row
# (ospku of pku, klsupported and klenabled of keylocker, intelpt of ptwrite, a padlock unit's _en
# bit), the leaf 1EH _mirrored amx bits that are the rows of their leaf 07H names, ace_vsn1 the ace
# row's version, and the avx10 version bits the version rows: avx10_enabled and avx10_ver1 avx10_1,
# avx10_ver2 avx10_2. intel64, CPUID.80000001H:EDX.LM, is 64-bit code, the state width=64. each line
# cites the cpuid line of XED that names the bit and the ruling of #29 that maps it, and XED states
# no row for any of them, so no line overrides it
