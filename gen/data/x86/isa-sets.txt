# the requirement of each ISA set of XED that XED gives no cpuid group
#
#   <ISA set> | none | <cites> | <overrides>
#   <ISA set> | requires=<atom> [[llvm=<bit_ name>] leaf=<n> subleaf=<n> reg=<r> bit=<n>] | <cites> | <overrides>
#
# a set XED names only as an instruction's ISA_SET, with no cpuid line, states nothing, and its
# line overrides `-`. a set whose every cpuid line is `n/a` XED states requires nothing, `none`,
# which is right for the sets every x86 processor executes (i86 to i486, pentiumreal, ppro, pause,
# rdpmc and prefetch_nop), so they have no line, and a line here overrides it for a set that does
# need a feature. where the feature has a CPUID bit XED does not name, the line states it. `llvm=`
# names the bit_ constant of clang's cpuid.h (gen/vendor/llvm-cpuid) it is read from, and gen holds
# the line to the leaf, subleaf and register of the heading above the constant and the bit of its
# mask. cpuid.h names no bit for svm, sce or invlpgb, so those lines are read from AMD's APM volume
# 3 (24594 3.38) Appendix E, which AMD does not allow redistributed, and are cited, not checked.
# x87 is the x87 row, whose bit XED names fpu, sse_prefetch's prefetches are sse's, amd's
# SYSCALL_AMD and SYSRET_AMD are sce's, ENCLV is sgx's, and tdx and vmfunc are their rows, which no
# bit of XED's enumerates
